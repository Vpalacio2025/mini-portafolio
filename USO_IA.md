# Registro de uso de inteligencia artificial

## 1. IA usada

Durante el desarrollo del portafolio se utilizaron dos herramientas de inteligencia artificial:

- **ChatGPT:** utilizado como apoyo para comprender conceptos de React, organizar componentes, corregir errores y desarrollar estilos CSS.
- **GitHub Copilot:** utilizado como apoyo para investigar errores durante la programación, explorar posibles soluciones y perfeccionar los estilos CSS.

## 2. Modelo

- **ChatGPT:** modelo de inteligencia artificial de OpenAI disponible a través de ChatGPT. La versión exacta debe indicarse según la información disponible en la herramienta utilizada.
- **GitHub Copilot:** asistente de programación integrado en el entorno de desarrollo. El modelo específico puede depender de la configuración y de la versión utilizada.

No se especifican versiones exactas cuando no se dispone de información verificable sobre ellas.

## 3. Prompts realizados

A ChatGPT se le solicitaron ayudas mediante instrucciones y preguntas relacionadas con las siguientes tareas:

- Explicar cómo organizar y desarrollar componentes en React.
- Utilizar propiedades (`props`) para transmitir información entre componentes.
- Mostrar listas de habilidades y proyectos utilizando arreglos de objetos y `.map()`.
- Incorporar HTML semántico y claves únicas (`key`) en los elementos generados.
- Identificar y corregir errores en las rutas de importación, la estructura de carpetas y la sintaxis de los componentes.
- Crear y organizar estilos CSS para mantener una apariencia coherente entre las páginas.
- Desarrollar y revisar las secciones del portafolio.

GitHub Copilot se utilizó para investigar errores, explorar alternativas de solución y mejorar la presentación visual mediante ajustes de CSS.

Estos puntos resumen las solicitudes realizadas; no constituyen una transcripción literal de todos los prompts utilizados.

## 4. Outputs

Las herramientas proporcionaron sugerencias y ejemplos de código que sirvieron como referencia para:

- Desarrollar y organizar componentes de React.
- Mostrar información mediante arreglos y `.map()`.
- Reutilizar componentes mediante propiedades (`props`).
- Corregir errores de importación y sintaxis.
- Crear o ajustar estilos CSS para las distintas secciones.
- Comprender posibles causas de errores durante el desarrollo.

Las sugerencias no se consideraron automáticamente correctas: fue necesario revisar su compatibilidad con la estructura y las necesidades del proyecto.

## 5. Ajustes

Las respuestas y sugerencias se revisaron y adaptaron al código existente. Entre los ajustes realizados se encuentran:

- Revisar las rutas de importación según la ubicación real de los archivos.
- Crear archivos CSS faltantes y corregir sus importaciones.
- Corregir la estructura de componentes con errores de sintaxis.
- Adaptar los ejemplos de React a las secciones de habilidades y proyectos.
- Organizar los estilos globales y específicos para mejorar la coherencia visual.

El código generado o sugerido se utilizó como apoyo y requirió revisión dentro del proyecto. La versión final debe corresponder a lo que realmente se haya incorporado y probado.

## 6. Reflexión crítica

El uso de inteligencia artificial facilitó la comprensión de conceptos de programación y permitió explorar soluciones a problemas que aparecieron durante el desarrollo. También sirvió como apoyo para organizar componentes y mejorar la presentación visual del portafolio.

Sin embargo, las sugerencias pueden contener errores, utilizar rutas incorrectas o proponer soluciones que no se ajustan a la estructura del proyecto. Por ello, es importante revisar el código, probarlo y comprender su funcionamiento antes de incorporarlo.

La experiencia permitió reconocer que estas herramientas pueden apoyar el aprendizaje y agilizar determinadas tareas, pero no reemplazan la comprensión personal ni la responsabilidad sobre el resultado final. Su uso debe ser transparente y crítico, indicando las tareas en las que efectivamente participaron.
